# Superstore Sales Analytics Dashboard

A sales dashboard built with Python, Pandas, NumPy, MySQL and Matplotlib, served through Streamlit.
It looks at revenue, profit, discounts and customer trends for a retail store.

**Live demo:** <add your Streamlit link here>

## What it does
- Loads order data from MySQL (or from a CSV when no database is set up)
- Cleans it with Pandas/NumPy: column names, dates, duplicates, derived columns like profit margin and discount bands
- Shows KPIs (sales, profit, margin, customers) with filters for year, region and category
- Matplotlib charts: monthly trend, profit by sub-category, sales by region, discount vs margin, segment split
- Top 10 customers table

## What the analysis shows (sample data)
- Discounts above 20% push the average margin below zero
- Tables, Machines and Bookcases lose money overall
- Check the live app for the rest, and re-run on the real dataset for your own numbers

## Project structure
```
app.py                  Streamlit dashboard
src/cleaning.py         data cleaning + feature columns
src/data_loader.py      MySQL / CSV loading
src/charts.py           Matplotlib charts
scripts/load_to_mysql.py  one-off loader for MySQL
scripts/make_sample_data.py  builds the sample CSV
sql/queries.sql         the SQL queries I used for analysis
data/                   CSV files
```

## Run it locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Using MySQL
```bash
# create the db first: mysql -u root -p < sql/schema.sql
export MYSQL_USER=root MYSQL_PASSWORD=yourpass MYSQL_DB=superstore
python scripts/load_to_mysql.py
streamlit run app.py
```
Without these variables the app reads `data/superstore.csv`, or `data/sample_superstore.csv` if that's missing.

## Data
The demo runs on a Superstore-style sample dataset generated by `scripts/make_sample_data.py`.
To use the original Superstore dataset from Kaggle, save it as `data/superstore.csv`.

## Notes
Streamlit Cloud can't reach a local MySQL server, so the hosted demo reads the CSV.
The Matplotlib charts are static; the filters are what make the dashboard interactive.
